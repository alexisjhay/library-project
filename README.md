<h1>Library Project</h1>

<p>A simple book library application built with HTML, CSS, and JavaScript. This project is part of The Odin Project curriculum, built to practice JavaScript fundamentals, including objects, constructors, and prototypes</p>

<h2>Features</h2>
<ul>
  <li>Add books with title, author, page count, and reading status.</li>
  <li>Display books as cards.</li>
  <li>Toggle reading status between read and unread.</li>
  <li>Delete books from the library.</li>
  <li>Track total, read, and unread books.</li>
</ul>

<h2>Technologies</h2>
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<p><strong>Note:</strong> Book data is stored in memory and resets when the page is reloaded.</p>
